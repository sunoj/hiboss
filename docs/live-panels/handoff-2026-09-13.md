# Handoff — Live Panels and boss identities, 2026-09-13

Four changes shipped to production today, each merged, deployed where it has a server part,
and installed as the local CLI. One rendering defect was diagnosed and left open.

## What is true now

**An omitted panel target resolves on the server.** Publication and
`GET /api/agents/me/bosses` share one query (admin, or granted, and not archived). The default
is the only resolved boss, or the sole admin among several; two admins still return 400 with
the reason. `hiboss panel doctor` prints names, roles, full IDs and the server's default
instead of bare IDs. Merge 8d4f98c.

**A boss can leave without losing history.** `bosses.archived_at` (migration 0046) removes a
boss from authentication and every live selection, and closes its open relay subscriptions
with code 4401. Grants, clients, tokens, panels, messages and audit rows stay; restore clears
the field. Archive refuses self and the last live admin. `docs/boss-archive.md` classifies
every boss-selection site. The legacy manager boss that the macOS client used before it
re-registered under the admin boss is archived. Merge 45f5e9f.

**A live panel needs live state.** The routing rule reads the same in the guide, the
`hiboss setup agents` template and `CLAUDE.md`: a panel only for state the boss would watch
change; a progress note, result or final report is `hiboss send`. `panel validate` and
`publish` reject a spec with no `$state` binding. Merge 04f2c3d.

**Agents can find the chart elements.** The guide chooses elements by data shape (Progress
with a real denominator, Metric without, LineChart or BarChart bound to a state array with
`null` gaps, Status, Table), its worked example is a download, and `hiboss panel example`
prints the four embedded publication fixtures. `validate` warns when a Metric label carries a
denominator. Merge b64e7df.

## Why the wall filled with report cards

The generated instructions said "one panel per execution, publish early" and described
`send` as a one-shot notice, so a plain completion report had no other home. Of 25 cards,
13 were one-shot reports and 3 held a single static Text element. The same pattern explains
charts: the guide's only worked example was a Metric grid and it never named a chart
element, so an agent drew a download as a number with the denominator in its label. Agents
use what the guide shows, not what the catalog contains.

## Open

- **Line charts flatten real variation.** Reproduced with a live card's series in headless
  Chrome. The web leaf (`HibossKit/Sources/HibossKit/Resources/PanelWeb/index.html`,
  `scaleFor`) forces the y-domain to include 0 in an 8:1 plot, so a 113–117 MB/s series is a
  straight line at the top; `preserveAspectRatio="none"` squashes point circles to invisible
  ellipses; no unit, latest value or y labels are shown. The native wall chart
  (`Panels/PanelDashboardChart.swift`) sets no `chartYScale`; that it also includes zero is
  inferred, not rendered. Fix: padded min..max domain in both renderers, undistorted points,
  latest value and unit beside the label. Requires rebuilding the macOS and iOS apps.
- `run_doctor` has helper-level tests only, no end-to-end test.
- Archive residual (THEORETICAL): a mutation authorized just before archival can complete
  after it; the preflight guard is not atomic with the write.
- Carried over from 2026-09-12: questionnaire submission from iOS fails with the generic
  token-rejected text; the server fault code has not been captured yet.
