## Retained data

Before deployment, all seven definitions and old relay snapshots were captured
without claiming producer leases. One card had a persisted relay observation;
the other six had only initial definition data. Every retained task passed the
v2 publication validator before any production mutation.

After deploying v2, each card was adopted through the normal definition API with
metadata/definition CAS and a stable idempotency key. Existing immutable definitions
remain in D1. Every new definition and checkpoint was read back and compared with
the captured task. No task was marked completed, failed, or cancelled by adoption.

The adopted data is a baseline, not a new live observation. Its observation time
is null until a v2 producer connects and supplies an actual observation. No old
producer was silently granted ownership or treated as healthy. Existing producers
must reconnect using the upgraded CLI.

## Verification

- The Worker dry-run build passed before deployment. Critical lifecycle and relay
  source hashes matched the isolated remote checkout that passed the final regression.
- Prior remote verification: complete server suite 644 passed; final Panels
  regression after the summary replacement fix 33 passed; CLI suite 185 passed;
  four real CLI lifecycle scenarios and guidance installer checks passed.
- Production D1 readback reports seven current v2 definitions and no current v1
  definitions. Historical immutable v1 definitions remain retained.
- All seven production HTTP definition/checkpoint readbacks matched the captured
  tasks after adoption.
- A production WebSocket check ran on the authorized remote E2E host using short-lived panel-scoped
  tickets passed over SSH. All seven subscriptions returned matching v2 snapshots,
  revision 2, null observation time, and current server clocks. The check never
  claimed a lease or changed task state. See the
  [relay log](../../output/panel-lifecycle/production-relay.log).
- The installed CLI exposes `guide`, `state`, `lifecycle`, and `definition`.

This does not constitute a native macOS UI E2E, an iOS device installation, an APNs
background delivery test, or a Dynamic Island test. No external report notification
or report upload was sent as part of this rollout.
