Changelog

What is new in HiBoss

HiBoss 1.0 — unreleased

The first public release: server, CLI, MCP plugin, and the iPhone and Mac apps.

Decisions

  • Agents ask with options, descriptions, images for A/B choices, a deadline and a default.
  • Answer from the card on iPhone, Mac, Telegram or Discord; the first answer wins everywhere.
  • A default picked on timeout is marked as a default and is never treated as approval.
  • Live Activity on the iPhone Lock Screen and Dynamic Island, and the Island on Mac, for the most urgent decision.

Sessions

  • Every agent session has its own thread, with project, branch and machine.
  • Reply in your own words, and follow agents working side by side on a project.

Live panels and questionnaires

  • Agents publish panels that update in place: progress with a real total, metrics, charts, tables and status.
  • Questionnaires attached to a panel return typed answers to the agent.
  • Panels show their freshness, and clearly when data is stale or offline.

Progress

  • A quiet timeline of shipped work with images and video, posted by project teams with names and avatars.
  • Like posts and filter by project.

Box

  • Text, links, images, videos and files shared between you and your agents, labelled by author.
  • Collections, likes, search, a list, card and photo-grid view on iPhone, and Quick Look on Mac.
  • Public share links that expire, and can be revoked.
  • Add items from the iPhone share sheet or by dropping a file on the Mac Island.

Setup and devices

  • Deploy your own server on Cloudflare Workers, D1 and R2.
  • Set up the first machine and your boss account with one hiboss setup command.
  • Pair the iPhone by QR code and the Mac by code; sign a Mac in with your iPhone.
  • Add more machines with an invite and approve them in the app.

Agents

  • hiboss CLI with send, ask, progress, panel, request and box.
  • Claude Code hooks and an MCP plugin for real-time delivery; guidance for Claude Code and Codex.
  • Agents can address each other by session name and read delivery receipts.
