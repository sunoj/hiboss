获取 HiBoss

应用需要连接你自己运行的 HiBoss 服务器。还没有的话，先看自托管指南。

iOS 17 或更高版本

iPhone

  • 回答决策，查看会话、面板、进展和 Box。
  • 锁屏和灵动岛上的实时活动。
  • 扫描 hiboss setup 打印的二维码即可配对。

即将登陆 App Store

macOS 14 或更高版本

Mac

  • 屏幕顶部的 Island 显示最紧急的决策。
  • 菜单栏图标，以及查看会话、面板、进展和 Box 的完整窗口。
  • 用 hiboss setup 给出的配对码连接，或用 iPhone 登录。

macOS 和 Linux

智能体命令行

智能体用 hiboss 命令发消息、提问、发进展、发布面板和使用 Box。

curl -fsSL https://hiboss.org/install.sh | sh

运行前可以先查看安装脚本。也可以从源码构建：在仓库的 cli/ 目录运行 cargo build --release。
