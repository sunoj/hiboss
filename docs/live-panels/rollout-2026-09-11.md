## Agent behavior

`cli/resources/agent-instructions.md` is the single prompt source for global setup,
Claude hook setup, and SessionStart. `hiboss setup agents` refreshes the managed
Codex/Claude blocks and the complete guide, removing the conflicting old communication
block while preserving unrelated instructions. Invalid or duplicate markers fail
before global destinations are changed. Repeated installation is idempotent.

The policy prefers one panel per execution for progress and final reports, durable
`hiboss request` forms for multiple fields, `send` for one-shot notices, `progress
post` for visual milestones, and `ask` only for required decisions. Completion no
longer requires an artificial next-step question. Stop marks the session waiting
without requiring an `ask`; SessionStart leaves unread messages available and does
not broadcast to peers automatically.

The guide includes a complete intake JSON document. Both that document and the
larger research fixture were published, read, and withdrawn by the remote CLI E2E.
Intake defaults remain drafts. Timeouts are never interpreted as answers or approval.

## Remaining scope

Native questionnaire code still requires client distribution and physical-device
verification. There is no questionnaire discovery push, shared attention ranking,
automatic agent callback, execution-authorization form, or Live Activity projection.
The guide tells agents to send a single HiBoss notice when a published questionnaire
needs immediate attention. A receipt acknowledges delivery, not execution.
