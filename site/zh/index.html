智能体来问，
你来拍板。

Claude Code、Codex 这样的 AI 智能体在干活时，会把要你决定的事、进展和结果都发到 HiBoss。你在 iPhone、Mac 或聊天应用里回复就行，所有消息都留在你自己运行的服务器上。

适合已经让智能体做正事、但仍想自己把关的人。

能做什么

需要你的事，都在一个地方

智能体继续干活，HiBoss 只把非你不可的事推到面前，其余的安静等着，你想看时再看。

点一下就能做决定

智能体提问时可以为选项附上图片和描述，并指定默认项与截止时间。你直接在卡片上比较、回答，最先给出的答案在所有设备上同时生效。

  • 每个问题都留在所属会话里，项目、分支、机器一目了然。
  • 到点没回复时可以自动选默认项，让工作继续；HiBoss 会标明这是默认项，绝不算你的批准。
  • 选项都不合适时，直接用自己的话回复。

可以盯着看的实时面板

对于会持续变化的工作，智能体可以发布一个面板：下载、测试、基准扫描或服务监控，内容原地更新。

  • 只有真有总量时才显示进度条，否则显示阶段、数值和更新时间。
  • 面板可以附带问卷，把结构化答案交回给智能体。
  • iPhone 和 Mac 上看到的是同一组面板。

值得展示的进展

智能体把做完的东西连同截图和短视频发到一条安静的时间线上。发帖不会推送通知，你想看时再翻。

  • 每个项目用自己的名字和头像发帖。
  • 可以按项目筛选，也可以点赞。

存放参考资料的 Box

把文字、链接、图片、视频和文件放进 Box，你提到时智能体就能找到。智能体也可以往里放东西，每一项都标明是谁加的。

  • 用合集整理，按标题、备注、项目或标签搜索。
  • 任意条目都能生成会过期的公开分享链接，随时可以撤销。
  • 可以从 iPhone 的分享菜单添加，也可以把文件拖到 Mac 屏幕顶部的 Island 上。

Mac 刘海

在 Mac 刘海，直接拍板

下一件需要你决定的事，出现在屏幕顶部。看清每个选项的描述和默认项，直接回复，无需打开主窗口。

可以点选，也可以用自己的话回复。答案与 iPhone 同步。

工作原理

智能体、你的服务器、你的应用

中间没有 HiBoss 云。智能体和应用只和你部署的服务器通信。

  1. 你的智能体

    通过 hiboss 命令行，或 Claude Code 里的 MCP 插件，发消息、提问、发进展、发布面板、读取 Box。

  2. 你的服务器

    运行在你自己 Cloudflare 账号里的 Worker，配合 D1 和 R2。它保存消息、转交回复，并记录每句话出自谁。

  3. 你的应用

    iPhone 和 Mac 上的 HiBoss，还可以加上 Telegram 或 Discord。在一处回复，处处同步。

# 智能体提问，并等待你的答复
hiboss ask --option "上线" --option "等等" --default "等等" \
  "现在把 v2.4 发布到生产环境吗？"

应用

在哪儿都能回复

iPhone

  • “今天”页面：什么需要你、什么在运行、刚收到什么。
  • 锁屏和灵动岛上的实时活动，显示最紧急的决策。
  • 通知里就能直接点选回答。经 HiBoss 推送中继发送时，内容在你的服务器和 iPhone 之间端到端加密。
  • 扫二维码即可配对。

Mac

  • 屏幕顶部的 Island 显示最紧急的决策和选项。
  • 菜单栏图标，以及查看会话、面板、进展和 Box 的完整窗口。
  • 用配对码连接，或用 iPhone 登录。

命令行与 MCP

  • 智能体只需一个命令：send、ask、progress、panel、box。
  • 钩子把你的回复带进 Claude Code 会话；MCP 插件实时送达。
  • 新机器加入时，在手机或 Mac 上批准。

Telegram 与 Discord

  • 同一台服务器上的可选渠道。
  • 消息发到聊天里，选项变成按钮，回复回到智能体。

开源 · 自托管

你的服务器，你的数据

HiBoss 以 MIT 许可开源。服务器部署在你自己的 Cloudflare 账号里，哪些智能体、哪些人能访问由你决定。没有托管账号，应用里也没有广告和统计分析。

每一行都可查

服务器、命令行、MCP 插件以及 iPhone 和 Mac 应用都在同一个公开仓库里。

访问权限明确

智能体经你批准后才能加入。每位负责人只看得到授权给他们的智能体。

出处一目了然

每条消息、每个回答、每个 Box 条目都标明来源：是你，还是哪个智能体、哪个会话。

放手让智能体干活，拍板的始终是你。

几条命令部署好服务器，再配对你的手机。
