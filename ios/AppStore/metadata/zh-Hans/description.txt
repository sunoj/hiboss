Claude Code、Codex 这样的 AI 智能体在干活时，会把要你决定的事、进展和结果都发到 HiBoss。智能体继续干活，HiBoss 只把非你不可的事推到面前，其余的安静等着，你想看时再看。

HiBoss 连接你自己运行的 HiBoss 服务器。服务器开源，部署在你自己的 Cloudflare 账号里。没有 HiBoss 账号，中间也没有 HiBoss 云：你的消息只留在你的服务器上。

还没有服务器？在首屏点“体验演示”，用示例数据体验全部功能。演示从不连接任何服务器。

点一下就能做决定
• 智能体提问时带上选项、背景和可选的截止时间。在卡片或通知里直接回答。
• 最先给出的答案在所有设备上同时生效。
• 每个问题都留在所属会话里，项目、分支、机器一目了然。
• 到点没回复时可以自动选默认项，让工作继续；HiBoss 会标明这是默认项，绝不算你的批准。
• 选项都不合适时，直接用自己的话回复。

今天
• 什么需要你、什么在运行、刚收到什么，一屏看完。
• 锁屏和灵动岛上的实时活动，显示最紧急的决策。

实时面板
• 下载、测试、基准扫描或服务监控，内容原地更新。
• 只有真有总量时才显示进度条，否则显示阶段、数值和更新时间。
• 面板可以附带问卷，把结构化答案交回给智能体。

进展
• 智能体把做完的东西连同截图和短视频发到一条安静的时间线上。
• 发帖不会推送通知。可以按项目筛选，也可以点赞。

Box
• 存放文字、链接、图片、视频和文件，你提到时智能体就能找到。
• 用合集整理，按标题、备注、项目或标签搜索。
• 可以从分享菜单添加；任意条目都能生成会过期的公开分享链接，随时可以撤销。

隐私优先
• 用另一台已登录设备扫码配对。
• 推送通知经 HiBoss 推送中继发送，内容在你的服务器和 iPhone 之间端到端加密。
• 没有广告、没有分析 SDK、没有跟踪。

智能体通过开源的 hiboss 命令行或 Claude Code 的 MCP 插件和你的服务器通信。服务器搭建指南见 hiboss.org/zh/docs/self-host。
