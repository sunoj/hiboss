# Native questionnaire UI verification — 2026-09-11

Follow-up: [native control fixes and current installed build](native-controls-fixes-2026-09-11.md).

## Delivered behavior

The macOS and iOS panel walls now expose **Needs input** and per-card pending
question counts. Both optional and blocking requests are included. Archive and
panel visibility expiry do not hide unanswered questions from this section;
questionnaire expiry and terminal task state remove them.

The shared editor shows loading/retry, deadlines, optional/blocking status, local
draft persistence, submission progress, and explicit receipt recovery. Accepted
answers display field and choice labels, acceptance time, and agent receipt status.
Recovery retains its submission ID until the matching accepted answer is read back.
The client never automatically resubmits an uncertain answer.

Native controls now show an unselected picker placeholder, preserve partially typed
decimals, display slider values, and avoid nested scrolling for multiple choices.
JSON Pointer writes correctly decode escaped keys, and numeric display/storage no
longer traps on large numbers or stores non-finite values. English and Simplified
Chinese copy is included.

The macOS packager compiles String Catalogs into runtime localization resources.
Package lookup resolves embedded app bundles for both localized copy and panel HTML,
so the installed app does not depend on a development build directory.
