# Security Policy

Security fixes are developed against the current `main` branch. Older tags may
not receive backports.

Send suspected vulnerabilities privately to **hi@hiboss.org**. Include the
affected component, steps to reproduce, and the expected impact. Do not post
live credentials or undisclosed vulnerabilities in public issues.

For a compromised credential in your own HiBoss deployment, revoke or rotate it
in that deployment. This repository cannot revoke keys issued by self-hosted
servers.
