HERE TO HELP

Support.

HiBoss is a client for your own server. Start with the setup guide, then connect the iOS app with a pairing code or Boss Token.

Get started

Follow the HiBoss quick start guide to deploy a server. The iOS app does not provide a hosted account. After your server is ready, use a pairing code from the Mac client or enter its URL and Boss Token in the app.

Notifications

In-app messages work through your configured server. Push notifications require APNs setup for the app's Apple signing team. Operators using their own Apple team need their own app build and bundle ID for push delivery. See the iOS setup guide for build and signing details.

Report a problem

For bugs and feature requests, open a GitHub issue. Do not post Boss Tokens, private messages, or other credentials in a public issue.

For account, privacy, or other non-public questions, email hi@hiboss.org.
